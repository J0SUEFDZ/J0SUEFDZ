## 🚀 About Me

Senior full-stack engineer with **7+ years** building SaaS products on **Ruby on Rails**, **React** and **AWS**.  
Most recently **Tech Lead** for Postmark at ActiveCampaign, where I owned billing end to end, led a 10-month template editor initiative and was technical lead for 6 senior contractors on the billing platform migration.

I take the cross-team problem nobody owns yet, ship it, and leave it documented so the team can run it without me. New stack? I have switched several times, and delivered early on each one.

## 🛠️ Selected Work

- **Next-generation template editor** (Postmark): spearheaded a 10-month initiative from concept to delivery, covering technical discovery, cross-functional alignment and executive communication.
- **Billing and payments** (Postmark): technical lead on the billing platform migration, built the pricing-tier integration, and was sole owner of billing incidents. Multiple live changes to production billing data with zero customer-facing billing errors.
- **Multi-agent framework for AI coding agents** (Postmark): human-in-the-loop write gates, risk-based model routing, and an agentic RAG documentation-search MCP server.
- **Customer Support tooling** (ActiveCampaign): rebuilt a legacy PHP support console as a React and TypeScript micro frontend, halving initial load time, and set up its Jest and Playwright testing strategy.
- **Legacy platform modernization** (SmarterSelect): moved a Rails 4 and jQuery monolith to a Rails 6 API with a React frontend.
- **GDPR consent enforcement** (Blue Apron): designed consent preferences in OneTrust and Google Tag Manager alongside the Braze to Segment migration.
